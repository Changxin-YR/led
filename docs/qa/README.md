# QA 证据目录

## 命名规范

- 构建记录：`YYYY-MM-DD-build.md`
- 交互记录：`YYYY-MM-DD-interaction.md`
- 前台证明：`YYYY-MM-DD-foreground.txt`
- 截图：`screenshots/YYYY-MM-DD-<场景>.png`

## 记录要求

- 标注设备/模拟器型号、OS版本、构建变体
- 标注bundle名和Ability
- 交互记录需包含前置/后置状态
- 截图保持原始分辨率，仅截取断言相关画面
- 宣传设计图不是设备运行时证明

## 隐私规则

- 不保存签名密码、私钥、token、个人信息
- 不保存无关的完整日志
