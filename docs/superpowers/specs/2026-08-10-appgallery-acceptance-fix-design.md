# AppGallery 上架整改设计

## 目标

用最小改动解决本次审核驳回的四类问题：应用名称缺乏识别性、安装后图标与提交图标不一致、界面对比度不足、状态栏和文字字号不符合规范。

## 范围

1. 将 AppScope 和 EntryAbility 的展示文字统一为 `LED跑马灯`。保持 `bundleName`、versionCode、versionName、签名配置不变。
2. 保留现有 1024x1024 分层图标，确保 AppScope 的应用图标和 EntryAbility 的任务图标使用同一套像素一致的前景/背景资源。启动窗口图标保持独立启动资源，避免改变启动流程。
3. 普通页面使用明确的页面背景作为状态栏背景，显示系统状态栏和导航栏，内容不延伸到系统栏安全区；`DisplayPage` 继续使用独立的全屏展示模式。
4. 提升固定 UI 文案的最低字号，清理 10/11 号辅助文案；统一正文、辅助文案、按钮文字与其背景的对比度。用户自定义 LED 字体颜色和全屏显示效果不改。
5. 增加或调整静态回归合同，检查名称、图标引用/资源一致性、普通页面窗口配置、最小固定字号和核心颜色对比度。

## 设计决策

- 复用现有 `AppTheme`、`ScreenService` 和分层图标资源，不引入新依赖或新 UI 框架。
- 以普通页面和系统栏为审核对象；全屏 LED 展示页是明确的独立使用场景，仍隐藏系统栏。
- 对比度检查针对应用自有固定文案和固定背景，动态 LED 颜色不做强制替换，以免破坏用户的展示目的。
- 不新增应用内说明页、权限、网络能力或设置项。

## 验收标准

- 生成的 HAP 中应用/Ability 对外名称为 `LED跑马灯`，包名和版本信息保持原值。
- 应用图标和最近任务图标引用的分层资源均为 1024x1024，前景/背景资源像素一致且无占位图标。
- 普通页面的状态栏、导航栏和页面背景连续，系统图标清晰，内容不被状态栏遮挡；进入和退出 `DisplayPage` 后窗口状态可恢复。
- 固定正文和辅助文字达到项目设定的最低字号；固定文字与背景达到现有合同要求的 4.5:1 正文、3:1 标题/图标对比度。
- `scripts/check-standard.ps1`、`scripts/build-harmony.ps1` 和可用设备安装启动验证通过；无设备时如实记录未验证的设备类型。

## 不在本轮

- 不重做页面视觉，不改变 LED 自定义颜色、不调整核心动画和路由。
- 不修改 bundleName、versionCode、versionName、签名、AGC 元数据或权限。
- 不承诺替代 AppGallery 控制台中的截图、资质、隐私声明等外部材料审核。
