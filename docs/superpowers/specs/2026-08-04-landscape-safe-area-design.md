# LED 展示横屏与安全区设计

## 目标

为 LED 滚动字幕应用补齐展示页横屏功能，并让常规页面使用与深黑蓝主题一致的系统栏颜色。常规页面的内容不得绘制到状态栏或系统导航栏区域。

## 已确认的用户体验

- 首页、模板、历史、颜色和计数器页面维持竖屏；系统状态栏与系统导航栏保持可见。
- 常规页面以系统安全区为内容边界，状态栏使用 `AppTheme.PAGE_BG`，系统导航栏使用 `AppTheme.PAGE_BG_DEEP`，图标为浅色。
- LED 展示页读取 `BannerConfig.isLandscape`：开启时旋转为横屏，关闭时保持竖屏。
- LED 展示页保持全屏播放，隐藏状态栏与系统导航栏；返回上个页面时恢复竖屏、显示系统栏、恢复自动亮度并关闭常亮。

## 方案比较

1. 全局全屏：所有页面都隐藏系统栏。视觉最连续，但会遮挡状态区并降低设置页可用性，不采用。
2. 常规页安全区 + 展示页全屏：常规页面保留并着色系统栏，展示页按配置横屏全屏。符合已确认的使用方式，采用。
3. 所有页面保留系统栏：展示页横屏但不全屏。退出路径稳定，但 LED 可用显示面积较小，不采用。

## 架构

`ScreenService` 负责窗口状态转换，避免页面直接拼接窗口 API 调用。它提供两组确定状态：

- `applyAppChrome()`：取消布局全屏、显示 status/navigation 系统栏、设置深黑蓝背景与浅色图标。
- `enterDisplayMode(landscape)`：按配置设置首选方向，然后进入布局全屏、隐藏系统栏、启用常亮与最大亮度。
- `exitDisplayMode()`：退出布局全屏、恢复竖屏、恢复系统栏主题、关闭常亮并恢复自动亮度。

`EntryAbility` 在窗口创建后初始化 `ScreenService` 并应用常规页系统栏主题。`DisplayPage` 只在进入和离开时调用展示模式转换；无论横屏开关状态如何，退出均恢复常规页窗口状态。

## 错误处理

- 单个窗口 API 调用失败时记录日志并继续执行后续恢复步骤，避免一次失败使系统栏、方向或亮度遗留在错误状态。
- 获取窗口失败时，展示页仍可使用现有页面尺寸与动画逻辑，不阻断内容显示。
- 展示页的尺寸在方向切换完成后重新读取，横向滚动和弹幕距离基于实际横屏宽度计算。

## 验收

- 首页截图中状态栏和系统导航栏背景与应用深黑蓝主题连续，页面内容不延伸到两处系统栏。
- 横屏开关开启后，进入 LED 展示页为横屏全屏；关闭时为竖屏全屏。
- 从两种展示状态返回后，首页恢复竖屏，状态栏和系统导航栏可见且配色正确。
- 新增静态窗口状态回归检查先失败后通过；`check-standard.ps1` 和 `build-harmony.ps1` 成功。
