# LED 滚动字幕 UI 还原设计

## 目标

以用户提供的三张设计稿为唯一视觉基准，在现有 HarmonyOS Stage 模型应用内完整还原首页、自定义颜色、场景模板、历史记录、计数器和应用图标，同时保持现有字幕播放、持久化与路由功能可用。

## 推荐方案

采用原生 ArkUI 组件化还原。公共颜色、间距和阴影集中到 `common/Theme.ets`，点阵预览抽到 `components/LedPanel.ets`，页面只负责组合与交互。该方案比单页堆叠更易保持五个界面一致，也比整屏位图背景具有真实可操作性和多设备适配能力。

不采用整屏截图铺底，因为它无法响应文字、颜色、计数与历史数据；不引入第三方 UI 框架，因为会增加包体和视觉偏差。

## 视觉系统

- 页面底色：`#030A16` 到 `#071426` 的深黑蓝层次，不使用大面积单色灰黑。
- 主强调色：`#00E5FF`，按钮使用青色到亮蓝的水平渐变。
- 面板：`#0A1628`，描边 `#183252`，圆角 10-16vp，重点区域增加青色外发光。
- 主文字：`#F5F8FF`；次级文字：`#A6B0C3`；弱提示：`#66738A`。
- LED 区域：黑底、规则青色微点阵、青色细描边，文本使用等宽观感和发光阴影。
- 布局以 390vp 手机稿为基准；宽屏时内容限制最大宽度并居中，模板网格按可用宽度增加列数。

## 页面设计

### 首页

顶部品牌为青色 `LED` 加白色“滚动字幕”，右侧历史入口。内容依次为点阵预览、带计数器的输入框、两行 8 个显示模式、两行颜色方案、速度和字号滑杆、三项开关、渐变主按钮。底部固定四项导航，当前项以青色图标和文字表示。

### 自定义颜色

顶部返回、标题和收藏图标。大尺寸点阵预览显示 `Aa 预览`，下方为十六进制颜色胶囊。色相轨道使用完整彩虹渐变，饱和度和明度使用与当前颜色一致的轨道；RGB 三列输入；最近颜色为圆形色样；底部为渐变确认按钮。

### 场景模板

顶部返回和标题，分类胶囊横向滚动。主体为双列卡片，每张卡片含点阵文字预览、名称和使用次数。点击后沿用现有编辑并播放流程。

### 历史记录

顶部返回、标题和红色清空操作。记录为纵向卡片，左侧点阵预览和时间/次数，右侧圆形删除按钮；点击卡片恢复并显示。

### 计数器

顶部返回和黄绿色重置。中央为大面积圆角点阵面板和青色发光数字，底部为红色减号、绿色加号两个发光圆形按钮。

## 数据与交互

保留 `BannerConfig`、`StorageService`、`TemplateService` 与 `DisplayPage`。首页所有控件实时更新预览；自定义颜色通过 `AppStorage` 返回；模板与历史继续向 `DisplayPage` 传递序列化配置；计数器加减与重置即时刷新。

## 验收

执行 UI 合同测试、`scripts/check-standard.ps1` 和 `scripts/build-harmony.ps1`。如可用模拟器在线，则安装启动并逐页验证；无法在线时在 `design-qa.md` 明确记录未完成的设备项。禁止修改 bundleName、versionCode 与签名配置。
