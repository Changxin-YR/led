# 光迹字幕用户协议

生效日期：2026年8月7日

欢迎使用光迹字幕。安装、启动或继续使用本应用，即表示用户理解并同意以下条款。

## 一、服务内容

本应用提供字幕编辑、动画展示、场景模板、历史记录、自定义颜色和本地计数器等单机功能。应用不提供账号、云同步、内容发布、社交互动或在线交易服务，也不承诺跨设备保存数据。

## 二、用户内容与使用责任

用户应当对主动输入和展示的文字、颜色及其他内容负责，并确保相关内容合法且不侵犯他人的姓名权、肖像权、名誉权、隐私权、知识产权或其他合法权益。不得使用本应用制作、展示或传播违法、有害、欺诈、骚扰、仇恨、暴力或侵犯他人权利的内容。

## 三、本地数据

应用配置和历史仅保存在当前设备。用户应自行管理重要内容，并理解清除应用数据、卸载应用、设备损坏或系统重置可能导致数据无法恢复。应用关闭系统备份，不提供服务器端恢复能力。

## 四、知识产权

应用的软件代码、界面设计、图标和随应用提供的模板受适用法律保护。用户保留其自行输入内容的合法权利，但不得对应用进行违法复制、销售、破解、篡改或绕过系统安全机制。

## 五、服务可用性与责任限制

应用按现状提供。开发者会合理维护兼容性和稳定性，但设备差异、系统升级、权限策略、存储故障或用户操作可能影响功能。法律允许的范围内，开发者不对用户违法使用、未备份内容丢失或超出应用合理控制范围的间接损失承担责任。

## 六、协议更新与终止使用

功能或法律要求发生实质变化时，协议将随版本更新。用户不同意更新后的条款时，可以停止使用并卸载应用。有关应用的问题可通过应用市场展示的开发者联系渠道反馈；该渠道应由实际上架主体维护。
