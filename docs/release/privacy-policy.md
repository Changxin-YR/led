# 光迹字幕隐私政策

生效日期：2026年8月7日

光迹字幕是一款无需账号、无需登录、完全离线运行的单机工具。本政策说明应用处理数据的实际方式。

## 一、数据处理范围

应用不会收集、上传、出售或向第三方共享个人信息，也不接入广告、统计、推送、登录、支付、地图、定位、通讯录、相机、麦克风或第三方分析服务。应用清单不申请网络权限，程序不建立网络连接。

用户主动输入的字幕文字、显示颜色、字号、动画模式、速度、镜像、边框和横竖屏设置，仅保存在当前设备的应用私有存储中。历史记录、最近使用颜色和计数器数值同样只用于本机功能。

## 二、本机存储与备份

应用使用 HarmonyOS Preferences 保存少量配置。系统备份与恢复功能已关闭，因此这些内容不会由应用请求备份或迁移到其他设备。应用没有云端服务器，也不提供跨设备同步。

## 三、数据删除

用户可以在历史记录页面清空字幕历史。最近颜色、计数器和其他本机配置可通过系统的“清除应用数据”功能删除；卸载应用也会删除应用私有目录中的本地数据。应用运营方无法远程读取、恢复或删除这些本机内容。

## 四、未成年人保护

应用不识别用户身份或年龄，也不面向未成年人收集任何信息。监护人可通过设备系统的应用管理功能清除数据或卸载应用。

## 五、政策更新与联系

如果后续版本增加联网、账号、第三方 SDK 或新的数据处理能力，将在功能启用前更新本政策并按法律法规取得必要授权。当前版本的问题可通过应用市场展示的开发者联系渠道反馈。应用市场中的开发者主体信息和联系渠道应与实际上架主体保持一致。
