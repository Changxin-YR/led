# AppGallery 上架检查清单

本清单区分仓库内可以验证的技术项目和必须由实际上架主体在 AppGallery Connect 完成的外部项目。签名配置按项目所有者要求保持不变。

## 一、仓库内技术状态

- [x] Stage 模型应用，设备类型声明为 phone、tablet、2in1。
- [x] `compatibleSdkVersion` 与 `targetSdkVersion` 为 HarmonyOS 6.0.2 API 22。
- [x] `requestPermissions` 为空，无网络权限、网络 SDK 或网络请求代码。
- [x] 系统备份恢复关闭，字幕、历史、颜色和计数器仅保存在应用私有存储。
- [x] 分层应用图标为 1024x1024：背景不透明，前景透明并保留至少 80px 安全区。
- [x] 商店功能文案与实现一致：8种模式、11种预设配色加自定义入口、静态彩色边框、点阵预览背景。
- [x] 隐私政策和用户协议源文件已准备，可由上架主体发布到正式可访问地址。

### 当前设备回归记录

- [x] API 22 phone（OpenHarmony 6.0.2.130）完成最终 Release HAP 安装启动、双击暂停/恢复、历史次数即时刷新、沉浸式进入和退出恢复。
- [x] 2in1（OpenHarmony 6.1.1.125）完成最终 Release HAP 安装启动、双击暂停/恢复和展示页返回。
- [ ] 当前无在线 tablet；tablet 布局、旋转、系统栏和商店截图必须在提交前补验。

## 二、提交前必须由上架主体完成

- [ ] 在 AppGallery Connect 填写与证书一致的开发者主体、应用分类、支持邮箱和联系电话。
- [ ] 确认软著、备案、许可或其他资质是否适用于实际上架地区和应用类别，并上传真实有效材料。
- [ ] 将隐私政策发布到审核可访问的正式地址，填写后台隐私政策字段；不得使用临时地址或不可访问链接。
- [ ] 上传与当前版本一致的 phone、tablet、2in1 截图。不得使用设计稿冒充运行截图。
- [ ] 在官方图标预览中检查圆形、圆角矩形等系统蒙版，确认 LED 主体未被裁切且小尺寸清晰。
- [ ] 使用正式发布证书生成 Release HAP，核对包名、版本、证书有效期和 AppGallery Connect 应用记录完全一致。
- [ ] 在 API 22 phone 上完成安装、启动、八种模式、单双击、历史计数、颜色、模板、计数器、横竖屏及退出恢复验收。
- [ ] 在真实 tablet 和 2in1 或对应官方模拟器完成布局、旋转、系统栏和返回路径验收。
- [ ] 复核商店标题、简介、详细描述、截图和实际功能一致，不宣传云同步、闪烁边框或全屏点阵字体等未实现能力。

## 三、本次驳回专项复核

- [x] 包内 AppScope、EntryAbility、首页、隐私政策和用户协议统一使用 `光迹字幕`。
- [x] 商店图标产物为 `docs/release/appgallery-icon.png`，1024x1024、全画布不透明、无预切圆角，并与包内图标使用同一分层源。
- [ ] AGC 商品名、简介、详细介绍、隐私资料和软件资质统一为 `光迹字幕`；开发者名称使用当前 AGC 主体的准确名称。
- [ ] 上传包含即时点击响应修复的最新正式包，并使用 AppAnalyzer 或 DevEco Testing 复测点击完成时延，`T2-T1 <= 900ms`。
- [ ] 核对新包安装后启动器、最近任务、隐私模块与 AGC 的名称和图标完全一致。
- [ ] AGC 保存、包上传和重新提审前确认具体字段、文件与账号，未经确认不产生外部写入。

## 四、提交产物留档

每次提交应记录 HAP 文件名、大小、SHA-256、构建日期、构建模式、签名证书到期日、测试设备系统版本和审核后台版本号。留档中不得记录签名密码、私钥、token 或用户输入内容。
